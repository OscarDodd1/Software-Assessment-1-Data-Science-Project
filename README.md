# Software-Assessment-1-Data-Science-Project

# !!!!! IMPORTANT: Use | pip install -r requirements.txt | to install all dependancies
```bash
pip install -r requirements.txt
```

### **Features**
#### -Get weather data from any location, or get weather data from your local location. The weather data includes temperature and condition.
#### -Saves users weather searches

### **How to use**
#### 1 - Install all of the dependencies by running the code above in the command line
#### 2 - After installing dependencies, copy your api key from the weather api website: https://www.weatherapi.com/
#### 3 - Run the program and input your api key when prompted. Without the api key the program is unable to fetch weather.
